# START_HERE.md — Taskbar Inn 再開入口メモ

このファイルは、Taskbar Inn の開発再開時に「現在の方針・呼称・次の実装予定」を30秒で確認するための入口メモです。
仕様の正本ではなく、`SPEC.md` / `ROADMAP.md` / `GAME_BALANCE.md` / `SESSION_NOTES.md` を置き換えません。

## プロジェクト概要

Taskbar Inn は、Windowsタスクバー常駐型のインクリメンタル宿屋経営ゲームです。
小窓で常駐し、展開画面で宿屋経営の状態確認と操作を行います。
本線は支店拡張ではなく、一軒の宿を Lv1 から Lv8 へ巨大化させることです。

## 現在の開発フェーズ

既存のゲームロジック、compact / expanded、左メニュー、各機能ページは維持します。
次フェーズは、宿屋ステージに仮キャラクター移動と作業演出を追加し、宿が稼働しているように見えるプロトタイプを作ることです。
ゲームバランスの数値は開発用の仮値が多いため、現時点では細かい数値調整を目的にしません。

## 用語

- 小窓 = `CompactView`。常駐用の最小表示。
- 展開画面 = `ExpandedView`。小窓から開く大きい画面全体。
- 左メニュー = 展開画面内で機能ページを切り替えるメニュー。
- 機能ページ = ホーム / 仕事 / 厨房 / 設備 / スタッフ / 道具 / ログ / 実績など、左メニューから開く各ページ。
- ホーム = `HomePanel`。宿の概要を見る最初のページ。
- 状態ボード = ホーム内の数値、在庫、通知、宿の状況を要約する情報表示。
- 宿屋ステージ = `InnVisualView`。背景、家具、キャラ、作業演出を表示する場所。
- ステージ枠 = 展開画面内で宿屋ステージを置く領域。
- 詳細モーダル = 必要な説明や詳細操作を一時的に開く画面。

## 呼称ルール

コード上の既存ファイル名やクラス名は現時点では変更しません。
`InnVisualView` は会話上「宿屋ステージ」、`ExpandedView` は「展開画面」、`HomePanel` は「ホーム」と呼びます。
ホーム内の数字・在庫・通知のまとまりは「状態ボード」と呼びます。
「管理UI」という曖昧な呼称はなるべく使いません。

## 現在の画面構造

小窓:
常駐用の最小表示。所持金、評判、客数、汚れ、食事在庫などの概要を短く表示します。

展開画面:
左メニューと機能ページで構成されます。
ホーム、仕事、厨房、設備、スタッフ、道具、ログ、実績などを切り替えます。
下段または専用領域に宿屋ステージを表示します。

宿屋ステージ:
背景画像または仮背景を表示し、今後はキャラ移動、作業アイコン、吹き出し、前景レイヤーなどを追加していきます。

## 次にやること

- 宿屋ステージに仮キャラを1体以上出す。
- 仮キャラが受付、客席、清掃ポイント、厨房などを巡回する。
- 到着時に清掃、もてなし、調理、収穫などの作業アイコンを出す。
- 作業中に、ほうき、湯気、ハート、キラキラなどの簡易演出を表示する。
- ゲームロジックは変更せず、表示演出だけを追加する。
